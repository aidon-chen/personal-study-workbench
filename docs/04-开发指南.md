# 开发指南

## 新增一道题

只改 `assets/js/quiz-data.js`，在数组末尾追加：

```js
{
  "id": "hw47-49",
  "no": 168,
  "chapter": "第四章 基本图形生成算法",
  "section": "4-7章作业",
  "source": "作业",
  "type": "选择题",
  "q": "题干\nA．选项一\nB．选项二",
  "a": "正确答案：B（选项二）"
}
```

检查三条：

1. `id` 全局唯一，不要复用已有 id。
2. `chapter` 与 `MAP_DATA` 中的章名完全一致（含序号与空格）。
3. `source` 只能是 `作业`、`思考题`、`押题` 之一，否则卡片标签会落到默认灰色样式。

刷新页面即可，章节下拉、题型下拉、来源标签都会自动跟随数据变化。

## 新增或修改知识点

只改 `assets/js/map-data.js`：

- 在对应章的 `children` 里加 `{ name: "...", d: "..." }`。
- 正文多段用 `\n` 分隔，面板会自动拆成多个 `<p>`。
- 需要挂课件截图时，在 `name` 里写 `（P12）` 或 `（P12-15）`，页码会解析成 `slides/<章目录>/p012.jpg`。

章节点必须带 `color`，否则连线和节点配色会变成透明。

## 调整批注行为

批注逻辑集中在 `panel-annotate.js`：

| 想改什么 | 位置 |
| --- | --- |
| 高亮颜色 | `map.css` 中的 `#panelBody .highlight-mengshou-wrap` |
| 圈划颜色、线宽 | `applyMark()` 里的 `color` / `strokeWidth` |
| 增加第二种圈划形状 | `applyMark()` 的 `type`，可用 `box`、`circle`、`underline`、`highlight` |
| 批注按什么维度分组 | `keyOf(node)`，当前用节点全路径 |
| 存储键名 | 文件顶部的 `KEY` |

注意：修改 `keyOf` 会让已有批注全部对不上旧键，等于清空历史。

## 调试方法

浏览器控制台直接调用模块：

```js
MapView.focusChapter("第五章 点线面符号生成算法");
QuizView.jumpToChapter("第五章 点线面符号生成算法");
JSON.parse(localStorage.getItem("cm_panel_anno_v1"));
```

无头 Chrome 做运行时断言（不弹窗、不改本地数据）：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-sandbox --user-data-dir=/tmp/cm-check \
  --virtual-time-budget=6000 --dump-dom \
  "file:///Users/aidon/Documents/大三上/计算机制图/课件/核心知识点/计算机地图制图思维导图.html"
```

想抓 JS 报错，加 `--enable-logging=stderr --v=0`，再过滤 `CONSOLE`。

## 修改后自检清单

1. 控制台无报错。
2. 导图：点节点出详情、展开收起、缩放都正常。
3. 题库：题卡总数、三个筛选器、章节联动正常。
4. 批注：划词高亮 → 写备注 → 切到别的节点 → 切回来，批注仍在。
5. 页签来回切换后导图尺寸正常（依赖 `MapView.refresh()`）。

## 已知限制

- 数据存本机，换浏览器不通用；题库记录可用页面上的导出/导入迁移，批注暂未提供导出。
- 节点正文大改后，旧批注锚点可能失效，失效条目会静默跳过。
- `file://` 下部分浏览器禁用 localStorage，只保留本次会话的数据。
