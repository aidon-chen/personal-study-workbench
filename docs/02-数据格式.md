# 数据格式

## 一、导图数据 `MAP_DATA`

树形结构，节点分四层：课程 → 章 → 主题 → 要点。

```js
window.MAP_DATA = {
  name: "计算机地图制图",
  d: "课程简介正文",
  children: [
    {
      name: "第一章 绪论",
      color: "#4C6FFF",        // 章的配色，下级节点继承
      children: [ /* 主题 */ ]
    }
  ]
};
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 节点名，也是章节联动的匹配依据 |
| `d` | string | 右侧面板正文，换行用 `\n` |
| `color` | string | 仅章节点需要，子节点自动继承 |
| `children` | array | 子节点，没有则视为叶子 |

说明：

- `name` 中的 `（Pxx）` 会被解析成 PPT 页码，自动在面板底部插入对应课件截图。
- 节点没有 `d` 但有子节点时，面板显示子节点清单。
- `parent`、`x/y/w/h`、`collapsed`、`pdf` 等字段由 `map-view.js` 运行时写入，**不要手写进数据**。

当前规模：1 个根节点、7 章、53 个主题、227 个要点。

## 二、题库数据 `QUIZ_DATA`

数组，每题一个对象。

```js
{
  "id": "hw13-01",              // 唯一，答题记录以它为主键
  "no": 80,                     // 全局题号，用于展示排序
  "chapter": "第一章 绪论",      // 必须与 MAP_DATA 的章名一致
  "section": "1-3章作业",        // 来源批次，显示在卡片上
  "source": "作业",              // 作业 / 思考题 / 押题
  "type": "选择题",              // 可选，缺省时由 section 推导
  "q": "题干（选项逐行写）",
  "a": "参考答案"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 全局唯一；改 id 等于丢了这道题的作答记录 |
| `no` | 是 | 展示用题号 |
| `chapter` | 是 | 章节筛选与联动的唯一依据 |
| `section` | 是 | 批次名，如 `1-3章作业`、`押题 · 选择题` |
| `source` | 是 | 三种来源：`作业`、`思考题`、`押题`，对应卡片上的三种颜色标签 |
| `type` | 否 | 有值时优先作为题型；无值时：`section` 为 `押题 · X` 取 X，否则记作「课后题」 |
| `q` | 是 | 题干，`\n` 换行；选择题把选项按行排在题干里 |
| `a` | 是 | 答案，支持 ```` ``` ```` 包裹的代码块 |

当前分布：167 题，作业 88、思考题 55、押题 24。

题型分布：选择题 97、判断题 10、简答题 2、综合题 3、课后题 55。

### id 命名约定

| 前缀 | 含义 |
| --- | --- |
| `q01`… | 原有课后思考题 |
| `y01`… | 押题 |
| `hw13-01`… | 1-3 章作业，40 题 |
| `hw47-01`… | 4-7 章作业，48 题 |

### 题干写法

选择题把选项写进 `q`，答案只写字母加括号注释：

```js
"q": "在计算机图形学中，用户根据需要而设计或选定的一类坐标系称为\nA．世界坐标系\nB．局部坐标系\nC．规格化坐标系\nD．设备坐标系",
"a": "正确答案：A（世界坐标系）"
```

## 三、本地存储

### `cm_quiz_progress_v1`

以题目 `id` 为键：

```js
{
  "q01": {
    "attempts": 2,                     // 作答次数
    "wrongs": 1,                       // 错误次数
    "last": "wrong",                   // right / wrong
    "lastAt": "2026-11-03T06:00:00Z",  // 最近一次作答时间
    "history": [                       // 每次作答的原文
      { "at": "...", "result": "right", "text": "用户填写的答案" }
    ],
    "notes": [                         // 错题笔记
      { "nid": "n1730...", "at": "...", "text": "笔记内容", "attemptNo": 1 }
    ]
  }
}
```

### `cm_panel_anno_v1`

以**知识点路径**为键（节点名用 ` / ` 连接），值为批注数组：

```js
{
  "第一章 绪论 / 定义与研究对象 / 定义：机助制图 CAC（P10）": [
    {
      "id": "高亮器生成的唯一 id",
      "text": "被选中的原文",
      "startMeta": { "parentTagName": "P", "parentIndex": 0, "textOffset": 4 },
      "endMeta":   { "parentTagName": "P", "parentIndex": 0, "textOffset": 12 },
      "note": "我的批注",
      "style": "box"          // 空字符串表示只高亮，box 表示圈划
    }
  ]
}
```

`startMeta` / `endMeta` 是 web-highlighter 的锚点格式：记录「第几个同标签元素 + 元素内第几个字符」。正文重绘后按同样结构还原，因此节点正文改动过多时旧批注可能失效（失效条目会被静默跳过，不影响其他批注）。
