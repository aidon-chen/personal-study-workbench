# 样式规范

## 文件分工

| 文件 | 作用域 | 内容 |
| --- | --- | --- |
| `base.css` | 全局 | 页面骨架、顶部标题栏、页签、通用按钮 |
| `map.css` | `#mapView` | 导图、右侧面板、批注工具栏 |
| `quiz.css` | `#quizView` | 题卡、统计条、筛选器、答案区 |

## 作用域规则

答题页与导图页来自两套不同来源的样式，直接混写会互相覆盖。约定：

1. 导图相关规则一律以 `#mapView` 或 `#panelBody` 开头。
2. 答题相关规则一律以 `#quizView` 开头。
3. 需要覆盖第三方库的默认样式时，用「id + 类」提高选择器权重，**不靠 `!important`**。

例如覆盖 web-highlighter 默认的黄色高亮：

```css
/* 库注入的是 .highlight-mengshou-wrap { background:#ff9 }，权重 (0,1,0) */
#panelBody .highlight-mengshou-wrap { background: rgba(76, 111, 255, .16); }
/* 我们的是 (1,1,0)，无需 !important 即可生效 */
```

## 布局要点

- `#app` 是左右结构：`#viewport` 弹性占满，`#splitter` 可拖动，`#panel` 定宽（默认 390px）。
- 窄屏（≤900px）切为上下结构，分割条隐藏。
- `#panelBody` 设 `position: relative`，作为 rough-notation 圈划 SVG 的定位容器，让图形跟随正文滚动。

## 命名习惯

- 结构类：`panel-title`、`card-top`、`anno-item`，用短横线。
- 状态类：`is-right`、`is-wrong`、`active`，用 `is-` 前缀或单词。
- 元素 id 用 camelCase：`panelBody`、`btn-reveal-all` 这类按钮除外，沿用短横线。

## 注释

只在两类地方写注释：

1. 不容易看懂的布局或层级关系（如圈划 SVG 的定位上下文）。
2. 选择器权重或作用域判断依据（如上面覆盖第三方样式那段）。

不要给显而易见的样式加注释。
