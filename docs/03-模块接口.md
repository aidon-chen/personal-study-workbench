# 模块接口

所有模块都是 IIFE，只在 `window` 上暴露一个对象。

## MapView（map-view.js）

```js
MapView.init({
  onPracticeChapter: name => {},   // 面板「练习本章题目」被点击
  onPanelReady: (node, body) => {} // 面板内容渲染完成，交给批注模块
});
MapView.focusChapter("第三章 理论基础与数据模型");
MapView.focusNode("直线 Bresenham");
MapView.refresh();
```

| 方法 | 说明 |
| --- | --- |
| `init(options)` | 只执行一次；重复调用直接返回 |
| `focusChapter(name)` | 展开并选中该章，滚动到可视区，刷新面板 |
| `focusNode(name)` | 深度优先查找节点，展开所有祖先并定位 |
| `refresh()` | 重绘 SVG（切回导图页签时调用，修正尺寸） |

名字匹配统一走 `norm()`：去掉空格、`、`、`，`。所以「第三章 理论基础与数据模型」与「第三章理论基础与数据模型」都能命中。

## QuizView（quiz-view.js）

```js
QuizView.init({
  onGoToChapter: name => {},  // 题卡上的章节标签
  onGoToNode: name => {},     // 题卡下方「相关知识点」
  findNodes: q => ["节点名"]   // 由 app.js 提供的关键词匹配
});
QuizView.jumpToChapter("第一章 绪论");
```

`findNodes` 由编排层注入，因为关键词匹配需要同时读题库与导图，属于跨模块逻辑。

## PanelAnnotate（panel-annotate.js）

```js
PanelAnnotate.init();                // 建工具栏，绑定高亮器；库缺失时静默降级
PanelAnnotate.mount(node, body);     // 面板每次重绘后调用
```

`mount` 内部顺序：清理上一节点的圈划 → 清空高亮器缓存 → 回填该节点历史批注 → 重画圈划 → 重建批注列表。**顺序不能调换**，否则锚点会错位。

对外不暴露任何存储方法；数据读写全部在模块内部完成。

## app.js

不导出对象，直接执行：

1. 计算题库与导图节点之间的关键词映射。
2. `PanelAnnotate.init()`。
3. `MapView.init({...})`、`QuizView.init({...})` 并注入联动回调。
4. 绑定两个页签的点击，默认显示导图。

## 全局命名空间一览

| 名称 | 来源 | 用途 |
| --- | --- | --- |
| `MAP_DATA` | map-data.js | 导图数据 |
| `QUIZ_DATA` | quiz-data.js | 题库数据 |
| `MapView` | map-view.js | 导图视图 |
| `QuizView` | quiz-view.js | 答题视图 |
| `PanelAnnotate` | panel-annotate.js | 批注模块 |
| `Highlighter` | vendor | web-highlighter 构造器 |
| `RoughNotation` | vendor | 圈划绘制 |

除以上七个外，不新增全局变量。

## 关键 DOM 节点

| 选择器 | 作用 |
| --- | --- |
| `#mapView` / `#quizView` | 两个页签容器，切换靠 `hidden` |
| `#map` / `#stage` / `#viewport` | SVG、缩放层、滚动容器 |
| `#panelBody` | 右侧正文，批注的根节点 |
| `#panelTag` | 批注工具栏插入点（`after`） |
| `#list` | 题卡容器 |
| `#chapter` / `#qtype` / `#status-seg` | 三个筛选器 |
| `#btn-reveal-all` | 一键展开答案 |
