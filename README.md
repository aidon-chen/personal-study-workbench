# 计算机地图制图 · 学习平台

把课程「知识图谱」和「课后练习」合并到一个页面的纯前端学习工具：左侧是可折叠的知识树，右侧是当前知识点的详细说明，另一个页签是带作答记录、批注、统计的题库。

**无需构建、无需安装依赖**。用 `node server.js` 启动本地服务后，批注与作答记录存入 SQLite；直接双击 HTML 也能用，此时退回浏览器 localStorage。

## 功能

| 模块 | 能力 |
| --- | --- |
| 知识图谱 | 七章知识树、节点展开收起、缩放平移、详情面板、对应 PPT 页截图 |
| 课后练习 | 167 道题（作业 88 · 思考题 55 · 押题 24）、章节/题型/状态筛选、作答记录、错题笔记、一键展开答案、导出导入 |
| 双向联动 | 题目上的章节标签 → 定位到导图；导图「练习本章题目」→ 筛选题库 |
| 详情批注 | 右侧正文划词高亮、写备注、方框圈划，按知识点分别保存 |

## 快速开始

推荐用本地服务（数据写入 SQLite）：

```bash
cd "课件/核心知识点"
node server.js
# 浏览器访问 http://127.0.0.1:8765/
```

- 数据库文件：`data/study.db`，备份直接复制该文件即可。
- 也可直接双击 `计算机地图制图思维导图.html`（`file://`），此时只写 localStorage，不与数据库同步。
- 端口可用环境变量改：`PORT=9000 node server.js`。

## 目录结构

```
核心知识点/
├─ 计算机地图制图思维导图.html   入口页，只搭骨架
├─ assets/
│  ├─ css/    base.css / map.css / quiz.css
│  ├─ js/     map-data / quiz-data / map-view / quiz-view / panel-annotate / app
│  └─ vendor/ web-highlighter、rough-notation（已本地化）
├─ slides/    ch1~ch7 课件图片
├─ server.js  本地服务（静态资源 + SQLite 接口，Node 内置 node:sqlite）
├─ data/      SQLite 数据库目录（首次启动自动创建 study.db）
└─ docs/      开发文档
```

## 本地数据

| 键 | 内容 |
| --- | --- |
| `cm_quiz_progress_v1` | 每题作答次数、错误次数、作答历史、笔记 |
| `cm_panel_anno_v1` | 按知识点路径保存的高亮、备注、圈划样式 |

两个键存放在 SQLite 的 `kv` 表中，键名与浏览器 localStorage 保持一致。通过服务打开时，页面启动会拉取数据库记录，并自动把浏览器里的旧数据迁移上去；服务不可用时退回 localStorage。

## 约定

1. 只用原生 HTML/CSS/JS，不引入构建工具与框架。
2. 视图模块之间不互相引用，跨模块协作全部由 `app.js` 转发。
3. 新增题目只改数据文件，新增功能只改对应模块，不动入口页。
